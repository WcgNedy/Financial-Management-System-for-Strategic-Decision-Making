# Financial Management System

 About the Project

This project was developed to help business owners make strategic financial decisions through integrated dashboards, automatic data consolidation and financial performance indicators.

The system provides visibility over cash flow, profitability, investments, accounts receivable and financial health, enabling data-driven decision making.

Project Overview

THE CHALLENGE

The client needed strategic financial insights to support business decisions and answer questions such as:

- Can the company afford salary increases?
- Is it financially healthy enough to invest?
- How much cash is currently available?
- How much revenue is still expected to be received?
- Is the business growing sustainably?
- How long can the current cash flow sustain operations?
- Which business areas are consuming the most resources?



THE SOLUTION

A Financial Management System developed with Google Sheets to provide strategic financial insights and support business decision-making through integrated dashboards and automatic data consolidation.



FEATURES

- Financial Health Analysis;
- Investment Tracking;
- Cash Flow Management;
- Accounts Receivable Analysis;
- Profit Margin Analysis;
- Upcoming Payments Management;
- Monthly Performance Analysis;
- Dynamic Dashboards;
- Automatic Data Consolidation;
- Spreadsheet Integration;
- Strategic Financial Indicators.
